# Bitrix App - Django Integration with Bitrix24

Комплексное Django-приложение для интеграции с Bitrix24 CRM, включающее в себя работу со сделками, контактами, товарами, сотрудниками и компаниями.

## 📋 Описание проекта

Данный проект представляет собой Django-приложение, разработанное для интеграции с API Bitrix24. Приложение состоит из нескольких модулей, каждый из которых отвечает за определенную функциональность в работе с CRM-системой.

## 🏗️ Архитектура проекта

Проект организован по принципу Django-приложений с модульной структурой:

```
bitrix_app/
├── integration_utils/          # Подмодуль для работы с Bitrix24 API
├── start/                      # Стартовое приложение
├── deals/                      # Работа со сделками
├── contacts/                   # Управление контактами
├── product/                    # Работа с товарами
├── company/                    # Управление компаниями
├── staff/                      # Работа с сотрудниками
├── .gitignore
└── .gitmodules                 # Конфигурация git-подмодулей
```

## 🚀 Функциональность

### 1. **Работа со сделками** (`deals/`)
- Отображение имени текущего Bitrix-пользователя
- Вывод последних 10 активных сделок
- Создание новых сделок с кастомными полями
- Фильтрация по статусу сделки

**Основные компоненты:**
- `deals/views/active_deals.py` - просмотр активных сделок
- `deals/views/add_deal.py` - создание новых сделок
- `deals/urls.py` - маршрутизация URL

### 2. **Управление товарами** (`product/`)
- Генерация QR-кодов для товаров
- Создание секретных ссылок на товары
- Отображение информации о товарах

**Ключевые особенности:**
- Безопасная генерация ссылок (UUID/Signer)
- Интеграция со сторонними библиотеками для QR-кодов
- Работа с изображениями и файлами товаров

### 3. **Работа с контактами** (`contacts/`)
- Импорт/экспорт контактов в форматах CSV и XLSX
- Эффективная обработка через batch API
- Поддержка кастомных полей

**Функции:**
- `contacts/views/import_contacts.py` - импорт контактов
- `contacts/views/export_contacts.py` - экспорт контактов
- `contacts/utils/` - утилиты для работы с файлами
- `contacts/api/` - API методы

### 4. **Управление сотрудниками** (`staff/`)
- Отображение иерархии сотрудников
- Статистика звонков за последние 24 часа
- Интеграция с телефонией Bitrix24

**Особенности:**
- Таблица "Сотрудник | Руководители"
- Фильтрация только активных пользователей
- Подсчет исходящих звонков длительностью >1 минуты
- Открытие профилей в слайдере через BX24 JS SDK

### 5. **Работа с компаниями** (`company/`)
- Интеграция с Яндекс.Картами
- Отображение адресов компаний на карте
- Работа с логотипами компаний

**Компоненты:**
- `company/views/company_map.py` - карта с адресами компаний
- Геокодирование через Yandex API
- Автоматическая загрузка и кэширование логотипов

### 6. **Стартовое приложение** (`start/`)
- Начальная страница приложения
- Базовая конфигурация и общие элементы

## 🔧 Технологии

- **Backend:** Django (Python)
- **Интеграция:** Bitrix24 REST API
- **Авторизация:** integration_utils (OAuth 2.0)
- **Карты:** Yandex Maps API
- **Файлы:** CSV, XLSX обработка
- **Frontend:** HTML, CSS, JavaScript (BX24 JS SDK)

## 🚀 Установка и запуск

1. **Клонирование репозитория:**
```bash
git clone https://github.com/SergeiSova/bitrix_app.git
cd bitrix_app
git submodule update --init --recursive
```

2. **Создание виртуального окружения:**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

4. **Конфигурация:**
```bash
cp .env.example .env
# Заполните .env файл необходимыми значениями
```

5. **Запуск приложения:**
```bash
python manage.py migrate
python manage.py runserver
```
